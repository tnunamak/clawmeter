Set up the Clawmeter browser extension

claude.ai and the Claude Console have no API for reset credits or prepaid API credits. This extension reads them in your browser and passes them to Clawmeter on this computer.

Set it up

  1. In the Clawmeter tray menu, choose Connect your browser for Claude resets and API credits… (later: Settings → Set up the browser extension…), or run clawmeter setup --browser-extension. Either one writes the extension folder:
  2. Paste your browser's extensions address into the address bar:
    Chromechrome://extensions
    Bravebrave://extensions
    Edgeedge://extensions
  3. Turn on Developer mode, click Load unpacked and choose the folder.
    On Linux the folder is hidden: in the file chooser, press Ctrl+L and paste the path.
  4. Click the Clawmeter icon in the browser toolbar. If you don't see it, pin it from the puzzle-piece menu. The popup shows what it reads and how to fix what it can't:
    • Reset credits are read while you're signed in to claude.ai and a claude.ai tab is open. They change rarely, so the tab doesn't have to stay open; Clawmeter shows how old each reading is. Open a pinned tab in the popup opens one.
    • API credits need you signed in to the Claude Console. They need no tab.
    A grey icon means the Clawmeter app isn't running. An orange ! means Clawmeter keeps refusing readings from this browser. Hover over the icon to see why.

Optional: more than one Claude account

Skip this if you use one Claude account. A browser session holds one Claude login, so give each extra account its own session. Pick either way, or both:

Containers, in one window (Brave)

Load the extension once. For each account, open claude.ai in its own container (right-click a tab, or the Containers button), sign in, and keep that tab open. For that account's API credits, also keep a Claude Console tab open in the same container.

Browser profiles (Chrome, Edge, Brave)

In each profile, load the extension from the same folder, then do step 4.

Add each account to Clawmeter as well (clawmeter providers source help claude). The popup marks an account Clawmeter doesn't track as not in Clawmeter.

Updates and privacy

After Clawmeter updates, click the reload arrow on the extension's card, or restart the browser.

The extension talks only to claude.ai, the Claude Console and Clawmeter at 127.0.0.1. What it reads and sends · Clawmeter. Firefox and Safari aren't supported yet.
