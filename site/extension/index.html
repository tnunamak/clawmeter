Set up the Clawmeter browser extension

claude.ai and the Claude Console have no API for reset credits or prepaid API credits. This extension reads them in your browser and passes them to Clawmeter on this computer.

Set it up

  1. In the Clawmeter tray menu, choose Connect your browser for Claude resets and API credits…, or run clawmeter setup --browser-extension. Either one writes the extension folder:
  2. Paste your browser's extensions address into the address bar:
    Chromechrome://extensions
    Bravebrave://extensions
    Edgeedge://extensions
  3. Turn on Developer mode, click Load unpacked and choose the folder.
    On Linux the folder is hidden: in the file chooser, press Ctrl+L and paste the path.
  4. Sign in to claude.ai and the Claude Console in this browser, and keep a claude.ai tab open. Reset credits can only be read through that tab; API credits need no tab.
  5. To check, click the Clawmeter icon in the browser toolbar. It lists each account it reads.

More than one Claude account

A browser profile holds one Claude login.

Brave: one container per account

Load the extension once. Open claude.ai in a container for each account (right-click a tab, or the Containers button), sign in, and keep that tab open. For that account's API credits, also keep a Claude Console tab open in the same container.

Chrome, Edge and others: one profile per account

Load the extension in each profile, from the same folder. In each profile, sign in to claude.ai and the Claude Console and keep a claude.ai tab open.

Add each account to Clawmeter as well (clawmeter providers source help claude). The popup marks an account Clawmeter doesn't track as not set up in Clawmeter.

Updates and privacy

After Clawmeter updates, click the reload arrow on the extension's card, or restart the browser.

The extension talks only to claude.ai, the Claude Console and Clawmeter at 127.0.0.1. What it reads and sends · Clawmeter. Firefox and Safari aren't supported yet.
