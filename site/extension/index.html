Set up the Clawmeter browser extension

claude.ai and the Claude Console have no API for your reset credits and prepaid API credits. This small extension reads them from your signed-in browser and sends them to the Clawmeter app on the same computer, and nowhere else.

Set it up

  1. Get the extension folder: in the Clawmeter tray menu choose Connect your browser for Claude resets and API credits…, or run clawmeter setup --browser-extension.
  2. Open your browser's extensions page. Paste the address into the address bar; pages can't link to it.
    Chromechrome://extensions
    Bravebrave://extensions
    Edgeedge://extensions
  3. Turn on Developer mode, click Load unpacked, and choose the extension folder.
    On Linux the folder is inside a hidden folder. In the file chooser, press Ctrl+L and paste the path.
  4. Keep a claude.ai tab open. Clawmeter reads reset credits through it. API credits are read through a Claude Console tab, or your signed-in session if none is open.
  5. Check it works: click the Clawmeter icon in the browser toolbar. It lists each Claude account it can see and whether the readings reach Clawmeter.

More than one Claude account

A browser profile is signed in to one Claude account at a time. To cover more, give each account its own session:

Brave: containers, one profile

Load the extension once. Open claude.ai in a separate container for each account (right-click a tab, or the Containers button) and sign in there. Keep one claude.ai tab open per account. The extension reads every open tab, so it sees every container's account.

Chrome, Edge and other browsers: one profile per account

Make a browser profile for each account and load the extension in each profile. They can all use the same folder. Keep a claude.ai tab open in each profile.

Each account must also be set up in Clawmeter, as a Claude source (clawmeter providers source help claude). Readings for accounts Clawmeter doesn't track are dropped, and the extension's popup shows them as not set up in Clawmeter.

Updates and privacy

Clawmeter keeps the folder up to date. After Clawmeter updates, click the reload arrow on the extension's card, or restart the browser.

The extension only talks to claude.ai, the Claude Console and Clawmeter at 127.0.0.1. Firefox and Safari aren't supported yet. Read what it reads and sends, or the Clawmeter project.
